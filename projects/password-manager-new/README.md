# 🔒 비밀번호 관리 프로그램

로컬 환경에서 동작하는 오프라인 비밀번호 및 키 관리 데스크톱 애플리케이션.

모든 데이터는 마스터 비밀번호 기반 암호화를 거쳐 로컬 파일에 저장되며, 외부 서버와의 통신이 일절 없다.

---

## 주요 기능

### 데이터 관리
* 비밀번호 / 키 관리 / AWS IAM 키 / TOTP(OTP) 4개 탭 구조
* 그룹별 분류, 검색(필드별/전체), 정렬
* 즐겨찾기 기능 (⭐ 상단 고정)
* CSV 내보내기 / 가져오기
* 삭제 취소(Undo) 지원

### 시스템 트레이 & 플로팅 검색창
* **시스템 트레이 상주** — X 버튼 클릭 시 종료/트레이 선택
* **전역 단축키** `Ctrl+Shift+`` — 어디서든 검색창 호출
* **플로팅 검색창** — 빠른 검색 + 테이블 형식 표시
* AWS 탭 우클릭 → 액세스키/시크릿키 개별 복사

### 보안
* 마스터 비밀번호 인증 후 앱 진입 (Argon2id 검증)
* AES 기반 Fernet 대칭 암호화로 데이터 파일 보호
* 비밀번호 자동 생성기 (길이, 대문자, 숫자, 특수문자 옵션)
* **클립보드 히스토리 방지** — `Win+V` 히스토리에 안 남음
* **스마트 클립보드 삭제** — 30초 후 삭제 (다른 값 복사 시 건너뜀)
* 1시간 무활동 시 자동 로그아웃 (시스템 유휴 시간 감지)
* 실행 시 데이터 파일 자동 백업 (`data.enc.bak`)

## 보안 설계

| 항목 | 상세 |
|---|---|
| 마스터 비밀번호 해싱 | Argon2id (argon2-cffi) |
| 키 파생 | PBKDF2-HMAC-SHA256, 600,000 iterations |
| 데이터 암호화 | Fernet (AES-128-CBC + HMAC-SHA256) |
| 솔트 | 64바이트 랜덤 (os.urandom) |
| 키 파일 권한 | 소유자 읽기/쓰기 전용 (0600) |
| 파일 쓰기 | 원자적 교체 (tmp → os.replace) |
| 클립보드 | 복사 후 30초 자동 삭제 + 히스토리 제외 |
| 자동 로그아웃 | 3600초(1시간) 무활동 시 종료 |

## 디렉토리 구조

```
password-manager/
├── main.py              # 진입점 — 마스터 비밀번호 인증 후 GUI 실행
├── gui.py               # 앱 셸 — Notebook, 메뉴, 트레이, 자동 로그아웃
├── floating_search.py   # 플로팅 검색창 — 빠른 검색 UI
├── tab_panel.py         # 탭 패널 — 시트 + 입력 폼 + 이벤트 핸들링
├── totp_tab.py          # TOTP 탭 — OTP 코드 생성 및 관리
├── dialogs.py           # 다이얼로그 (수정, 비밀번호 생성, 마스터 변경)
├── service.py           # 비즈니스 로직 — 중복 검사, 디바운싱 저장
├── storage.py           # 암호화 저장소, CSV I/O
├── crypto.py            # 암호화/복호화, 마스터 비밀번호 검증
├── styles.py            # ttk 스타일 및 색상 팔레트
├── constants.py         # 필드 정의, 타이머 상수, 네임스페이스 키
├── keys/                # (자동 생성) 마스터 키 파일
│   └── blue_archive.json
└── data/                # (자동 생성) 암호화 데이터 파일
    └── data.enc
```

## 요구 사항

* Python 3.12+
* Windows 10 1903+ (클립보드 히스토리 방지 기능)

### 의존 패키지

| 패키지 | 용도 |
|---|---|
| `cryptography` | Fernet 암호화, PBKDF2 키 파생 |
| `argon2-cffi` | Argon2id 비밀번호 해싱 |
| `tksheet` | 스프레드시트 스타일 테이블 위젯 |
| `pystray` | 시스템 트레이 아이콘 |
| `Pillow` | 트레이 아이콘 이미지 |
| `keyboard` | 전역 단축키 |
| `pyotp` | TOTP 코드 생성 |

```bash
pip install cryptography argon2-cffi tksheet pystray Pillow keyboard pyotp
```

## 실행

```bash
python main.py
```

최초 실행 시 마스터 비밀번호를 입력하면 `keys/blue_archive.json` 키 파일이 자동 생성된다.

## 주의 사항

* `keys/blue_archive.json` 파일이 삭제되면 기존 데이터를 복호화할 수 없다.
* `data.enc` 파일이 손상되면 `.bak` 백업 파일로 복구를 시도할 수 있다.
* CSV 내보내기 시 비밀번호/키 값이 평문으로 저장되므로 취급에 주의해야 한다.
* 전역 단축키(`keyboard` 라이브러리)는 관리자 권한이 필요할 수 있다.
