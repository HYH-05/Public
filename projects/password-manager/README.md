# 🔒 비밀번호 관리 프로그램

로컬 환경에서 동작하는 오프라인 비밀번호 및 키 관리 데스크톱 애플리케이션.

모든 데이터는 마스터 비밀번호 기반 암호화를 거쳐 로컬 파일에 저장되며, 외부 서버와의 통신이 일절 없다.

---

## 주요 기능

* 마스터 비밀번호 인증 후 앱 진입 (Argon2id 검증)
* AES 기반 Fernet 대칭 암호화로 데이터 파일 보호
* 비밀번호 관리 탭 / 키 관리 탭 / AWS IAM 키 탭 삼중 구조
* 그룹별 분류, 검색(필드별/전체), 정렬
* 비밀번호 자동 생성기 (길이, 대문자, 숫자, 특수문자 옵션)
* CSV 내보내기 / 가져오기
* 셀 더블클릭 시 클립보드 복사 → 15초 후 자동 삭제
* 3분 무활동 시 자동 로그아웃
* 삭제 취소(Undo) 지원
* 마스터 비밀번호 변경 (원자적 처리 + 실패 시 롤백)
* 실행 시 데이터 파일 자동 백업 (`data.enc.bak`)

---

## 보안 설계

| 항목 | 상세 |
|---|---|
| 마스터 비밀번호 해싱 | Argon2id (argon2-cffi) |
| 키 파생 | PBKDF2-HMAC-SHA256, 600,000 iterations |
| 데이터 암호화 | Fernet (AES-128-CBC + HMAC-SHA256) |
| 솔트 | 64바이트 랜덤 (os.urandom) |
| 키 파일 권한 | 소유자 읽기/쓰기 전용 (0600) |
| 파일 쓰기 | 원자적 교체 (tmp → os.replace) |
| 클립보드 | 복사 후 15초 자동 삭제 |
| 자동 로그아웃 | 180초 무활동 시 종료 |

## 디렉토리 구조

```
password_tool/
├── main.py            # 진입점 — 마스터 비밀번호 인증 후 GUI 실행
├── crypto.py          # 암호화/복호화, 마스터 비밀번호 검증 및 변경
├── storage.py         # 3-네임스페이스 암호화 저장소, CSV I/O
├── service.py         # 비즈니스 로직 — 중복 검사, 디바운싱 저장
├── gui.py             # 앱 셸 — Notebook, 메뉴, 상태바, 자동 로그아웃
├── tab_panel.py       # 탭 패널 — 시트 + 입력 폼 + 이벤트 핸들링
├── dialogs.py         # Toplevel 다이얼로그 (수정, 비밀번호 생성, 마스터 변경)
├── styles.py          # ttk 스타일 및 색상 팔레트
├── constants.py       # 필드 정의, 타이머 상수, 네임스페이스 키
├── keys/              # (자동 생성) 마스터 키 파일 저장 디렉토리
│   └── blue_archive.json
└── data/              # (자동 생성) 암호화 데이터 파일 저장 디렉토리
    └── data.enc
```

## 요구 사항

* Python 3.12+
* 의존 패키지:

| 패키지 | 용도 |
|---|---|
| `cryptography` | Fernet 암호화, PBKDF2 키 파생 |
| `argon2-cffi` | Argon2id 비밀번호 해싱 |
| `tksheet` | 스프레드시트 스타일 테이블 위젯 |

```bash
pip install cryptography argon2-cffi tksheet
```

tkinter는 Python 표준 라이브러리에 포함되어 있으나, 일부 리눅스 배포판에서는 별도 설치가 필요하다.

```bash
# Debian / Ubuntu
sudo apt install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

## 실행

```bash
cd password_tool
python main.py
```

최초 실행 시 마스터 비밀번호를 입력하면 `keys/blue_archive.json` 키 파일이 자동 생성된다.

이후 실행부터는 동일한 마스터 비밀번호로 인증해야 앱에 진입할 수 있다.

## 데이터 구조

내부적으로 3-네임스페이스 JSON 구조를 Fernet으로 암호화하여 `data.enc`에 저장한다.

```json
{
  "passwords": {
    "기본 그룹": [
      {
        "_id": "a1b2c3d4e5f6",
        "이름(중복 불가)": "서버 A",
        "IP/도메인(중복 불가)": "192.168.0.1",
        "OS/환경": "Ubuntu 22.04",
        "ID/이메일": "<email>",
        "비밀번호": "<password>",
        "비고": "-"
      }
    ]
  },
  "keys": {
    "기본 그룹": [
      {
        "_id": "f6e5d4c3b2a1",
        "이름(중복 불가)": "GitHub Token",
        "서비스/플랫폼": "GitHub",
        "키 유형": "Personal Access Token",
        "키 값(중복 불가)": "<key>",
        "연결 계정/이메일": "<email>",
        "만료일": "2026-12-31",
        "비고": "-"
      }
    ]
  },
  "aws_keys": {
    "기본 그룹": [
      {
        "_id": "c3d4e5f6a1b2",
        "연결 계정": "<account>",
        "액세스 키(중복 불가)": "<access_key>",
        "시크릿 키(중복 불가)": "<secret_key>",
        "권한": "AdministratorAccess",
        "비고": "-"
      }
    ]
  }
}
```

## 비밀번호 탭 필드

| 필드 | 비고 |
|---|---|
| 그룹 | 분류용 |
| 이름 | 중복 불가, 필수 |
| IP/도메인 | 중복 불가, 필수 |
| OS/환경 | - |
| ID/이메일 | - |
| 비밀번호 | 마스킹 표시 |
| 비고 | - |

## 키 관리 탭 필드

| 필드 | 비고 |
|---|---|
| 그룹 | 분류용 |
| 이름 | 중복 불가, 필수 |
| 서비스/플랫폼 | - |
| 키 유형 | - |
| 키 값 | 중복 불가, 필수, 마스킹 표시 |
| 연결 계정/이메일 | - |
| 만료일 | - |
| 비고 | - |

## AWS IAM 키 탭 필드

| 필드 | 비고 |
|---|---|
| 그룹 | 분류용 |
| 연결 계정 | 중복 허용 |
| 액세스 키 | 중복 불가, 필수 |
| 시크릿 키 | 중복 불가, 필수, 마스킹 표시 |
| 권한 | - |
| 비고 | - |

> 중복 불가 필드에 `-`를 입력하면 비우기 및 중복이 허용된다.

## 단축 조작

| 조작 | 동작 |
|---|---|
| 셀 더블클릭 | 해당 셀 값 클립보드 복사 (비밀번호/키 값은 실제 값 복사) |

## 주의 사항

* `keys/blue_archive.json` 파일이 삭제되면 기존 데이터를 복호화할 수 없다.
* `data.enc` 파일이 손상되면 `.bak` 백업 파일로 복구를 시도할 수 있다.
* CSV 내보내기 시 비밀번호/키 값이 평문으로 저장되므로 취급에 주의해야 한다.
* 마스터 비밀번호 변경 중 오류 발생 시 자동 롤백이 수행된다.
